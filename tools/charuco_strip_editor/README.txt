ChArUco-полотно 12x3 м и редактор карт ArUco

editor/aruco_map_editor.html   - редактор, открывается в браузере без сервера
                                 (dicts_data.js и gen_dicts.py - служебные, словари уже встроены в html)
charuco_strip_12x3/
  charuco_strip_12x3_editor_project.json - проект для редактора: Проект -> открыть, или перетащить на холст
  charuco_strip_12x3.svg                 - вектор в миллиметрах, всё полотно 12000x3000, в печать
  charuco_strip_12x3_full_scale.pdf      - вектор в натуральную величину (страница через /UserUnit, PDF 1.6)
  charuco_strip_12x3_1to10.pdf           - тот же рисунок 1:10 (1200x300 мм), печатать с масштабом 1000 %
  charuco_strip_12x3_board.json          - параметры для OpenCV и координаты углов/маркеров
  charuco_strip_12x3_map.txt             - карта маркеров в формате дрона

Полотно: 12.000 x 3.000 м, белая кайма 375 мм с каждой стороны, внутри доска 30x6 клеток
по 375 мм, маркеры 280 мм, DICT_5X5_250, ID 0..89, 145 шахматных углов.
OpenCV: cv2.aruco.CharucoBoard((30, 6), 0.375, 0.280, DICT_5X5_250), marginSize = кайма.
Первая клетка доски (за каймой, левый верхний угол) чёрная, маркер ID 0 во второй клетке первой строки.
