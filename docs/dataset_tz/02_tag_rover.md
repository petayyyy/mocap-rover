# Промпт 02 — ровер с меткой на 11 м/с

Прочитай `docs/dataset_tz/README.md` и отчёт по промпту 01. Цель: tag_rover
проходит все критерии приёмки на `artifacts/dataset_imx219_01/`.

## Что сделать

1. **Время.** Каждое измерение помечать временем экспозиции кадра, а не
   временем прихода. Добавить в наблюдение поле поправки по строке:
   `stamp_ns + row * line_time_ns`, где `row` — строка центра маркера,
   `line_time_ns` — параметр (в датасете 0, у IMX219 около 9500 нс). Поле
   должно быть в `Observation.pixel_features` и учитываться фильтром.
2. **Окно вместо кадра.** Планировщик ROI (`localization_contracts/roi_tracker.py`)
   должен работать с fisheye-проекцией и обеими плоскостями маркера. Полный
   кадр только при `acquire`, `watchdog` и после `roi_exhausted`. Целевая
   стоимость: ROI-детекция ≤ 1 мс, полный кадр ≤ 6 мс на 1640×1232.
3. **Детектор.** Оставить OpenCV ArUco/AprilTag на CPU. Разрешено включить
   `useAruco3Detection` и `CORNER_REFINE_APRILTAG` для полного кадра, если это
   даёт выигрыш, измеренный на датасете. Порог `min_side_px` подобрать так,
   чтобы ровер держался на краю зоны 65° падения.
4. **Наблюдатель.** XY только из пересечения луча с плоскостью маркера, PnP
   для yaw и гейтов, как сейчас. Проверить, что fisheye-луч строится через
   `CameraModel.undistort` и что гейт `outside_model_domain` не режет кадр.
5. **Фильтр.** IMM оставить; проверить coast/lost при 80 fps и 6 камерах:
   `coast_ms`, `identity_max_age_s`, гейты. Выход должен оставаться `valid`
   между кадрами, когда маркер виден хотя бы одной камере.
6. **Лидар.** Подключить `lidar_pipeline.ArenaLidar` к реплею: фон записать
   из `artifacts/dataset_imx219_01_background/lidar/` (по образцу
   `scripts/record_lidar_background.py`, но из npz-файлов, без Gazebo).
   Кластер лидара как измерение-продолжение с per-scan меткой времени.
7. **Замер.** `timing.json` с P95 обработки кадра, доля кадров в режимах
   acquire/roi/idle/watchdog по камерам.

## Запрещено

Обучаемые детекторы; чтение эталона в рантайме; ослабление оценщика; отдельный
конвейер, который не сможет работать для соперника (промпт 03 переиспользует
планировщик окон, ray-plane и фильтр как есть).

## Сдать

Отчёт по шаблону. Дополнительно: таблица ошибок XY по дальности от ближайшей
камеры (0–2, 2–4, 4–6 м) и по скорости (< 3, 3–8, > 8 м/с). Если критерий не
достигнут, назвать доминирующую причину с числами из `observations.jsonl`
(причины отказов PnP, доля fusion_gate, и т. д.).
