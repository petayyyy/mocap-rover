синтетическим сенсором на ноутбуке. Все числа ниже, помеченные

Арифметика для шести камер по 1 GbE: полный Y8 кадр 2.02 МБ = 16.2 Мбит;

одновременно брать `--divisor 16` или `--format jpeg`.

## Что не сделано и почему

- Ни одного замера на CM4/CM5: модуля с камерой и кабелей ещё нет.
  Все пороги приёмки, кроме «тесты зелёные» и «читается replay_dataset.py»,
  ждут железа.
- `stamp_reference` по умолчанию — `readout_start_first_row` (гипотеза о
  FS-прерывании unicam/CFE), не измерение. До светодиодного теста `stamp_ns`
  может быть смещён на величину до экспозиции (0.5–1 мс) — это как раз то,
  что запрещено оставлять непроверенным.
- `line_time_ns` = 9452 нс — регистровая модель IMX219 (3448 такта при
  182.4 МГц, ×2 в биннинге 8 бит), не измерение.
- Зерокопийный путь через `MappedArray(request, "main", reshape=False)`
  написан по документации picamera2 с запасным вариантом для старых версий;
  на живом узле надо посмотреть `capture_cost_us` в статусе (на синтетике
  60–90 мкс на кадр с двумя окнами).
- Аппаратные метки PTP: не известно, есть ли PHC у сетевой карты Lenovo
  Legion; без них — программный PTP и честная цифра точности из
  светодиодного теста.
