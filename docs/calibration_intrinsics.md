# Внутренние параметры камеры (fisheye) — три разрешения за один сеанс

Цель: K и D каждой IMX219-160 в модели fisheye (equidistant, `cv2.fisheye`) по
ручной ChArUco-доске. Один набор кадров с полного сенсора даёт **три калибровки**:

| разрешение | откуда | где используется |
|---|---|---|
| **1640×1232** | полный кадр сенсора | окна маркера, полный кадр, внешняя калибровка |
| **820×616** | кадр, уменьшенный узлом 2×2 | малый поток половинного размера |
| **640×480** | кадр, уменьшенный узлом (2×2, затем по площади) | малый поток `640x480@30` |

Уменьшение делается ровно как в узле (`pi_cam.camera_node.scale_luma`), и каждое
разрешение калибруется по своим уменьшенным кадрам заново: углы ищутся там, а не
пересчитываются из полного. Пересчёт K полного кадра на меньшее разрешение
показывается рядом как контроль (`K_scaled_from` в JSON).

| | |
|---|---|
| запуск | `scripts/hardware/calibrate_intrinsics.sh start camera_3` → http://localhost:8090, вкладка «Внутренние параметры» |
| без железа | `scripts/hardware/calibrate_intrinsics.sh demo` |
| по готовой папке кадров | `scripts/hardware/calibrate_intrinsics.sh offline <папка> camera_3` |
| код | `localization_contracts/charuco_calibration.py`, `scripts/calibration_station.py`, `scripts/calibrate_intrinsics.py` |

Это та же станция, что и для [взаимного положения](calibration_extrinsics.md):
отдельная вкладка на выбранной камере. Подготовка узлов, свет и сеть — там же,
раздел «Что нужно до начала», пункты 3–4.

## Доска

По умолчанию — A4-доска пакета
[sverk-ros2 / camera_calibration](https://github.com/sverk-tech/sverk-ros2/tree/main/peripheral/camera_calibration):
`boards_examples_a4/calib.io_charuco_297x210_8x11_22_16_DICT_4X4.pdf` —
11×8 клеток по 22 мм, маркеры 16 мм, `DICT_4X4_50`.

- Печатать в масштабе 100 %, наклеить на жёсткое и плоское (стекло, композит).
  **Измерить клетку линейкой**: если не 22.0 мм, передать фактический размер
  (`--board-square-mm 21.8`). Масштаб доски входит в масштаб всей калибровки.
- Раскладка углов: доски calib.io и OpenCV < 4.6 с чётным числом рядов используют
  «старую» раскладку. По умолчанию (`--board-layout auto`) станция пробует обе и
  закрепляет ту, что нашла больше углов; выбранная видна в описании доски.
- Другая доска:
  ```bash
  scripts/hardware/calibrate_intrinsics.sh start camera_3 --board-squares 9 6 --board-square-mm 30 --board-marker-mm 22 --board-dict DICT_5X5_100
  ```

## Порядок работы (одна камера)

1. Запуск:
   ```bash
   scripts/hardware/calibrate_intrinsics.sh start camera_3
   ```
   Другая камера выбирается кнопками вверху вкладки. Выбранная камера идёт на
   20 Гц (или 10, см. шапку), остальные на 2 Гц, чтобы не занимать канал.
2. Большой кадр: зелёные точки — найденные углы доски. Подложка клетками
   показывает, сколько углов уже снято в каждой части кадра: красное — ни одного,
   жёлтое — мало, зелёное — достаточно.
3. Снимать **35 кадров** (рекомендация; меньше 5 калибровка не запускается):
   - доска на 0.2–0.5 м, целиком или почти целиком в кадре;
   - покрыть **весь кадр, особенно края и углы**: у fisheye дисторсия определяется
     краем поля зрения, без краёв D получается неверным;
   - наклоны доски до 40–50° в разные стороны, несколько кадров вблизи и издалека;
   - доска неподвижна в момент снимка (смаз портит углы).

   Кнопки: **«Снять кадр»** — текущий кадр, если найдено ≥ 12 углов;
   **«Автозахват»** — кадр снимается сам, когда доска неподвижна (сдвиг углов
   < 1.5 px между соседними кадрами) и стоит иначе, чем на всех снятых (средний
   сдвиг общих углов > 40 px), не чаще раза в 0.8 с; на 35 кадрах выключается сам;
   **«Убрать последний»** — кадр уходит в `rejected/` и в расчёт не попадает.
4. **«Калибровать»**. Для каждого из трёх разрешений: калибровка fisheye
   (`RECOMPUTE_EXTRINSIC`, `FIX_SKEW`, начальное приближение — объектив 160° по
   диагонали), затем отсев как в sverk: кадры с плохой обусловленностью
   (`CALIB_CHECK_COND`) убираются, потом худший кадр убирается, пока его средняя
   ошибка больше 2 px (`--max-frame-err`), но не меньше половины кадров.
5. Таблица: кадров использовано/снято, RMS, средняя ошибка, fx, fy, cx, cy,
   горизонтальный угол обзора, сколько отсеяно; ниже D (k1…k4) и путь к файлам.
6. Повторить для остальных пяти камер. Объективы одной модели всё равно
   отличаются, калибровать каждую.

## Что считать хорошим результатом

| | норма |
|---|---|
| средняя ошибка репроекции, 1640×1232 | < 0.5 px хорошо, < 1 px допустимо; больше — переснять (смаз, мало краёв) |
| отсеяно | 0–3 кадра; много — доска гнётся или неверный размер клетки |
| fx ≈ fy | различие < 0.5 % |
| cx, cy | в пределах ~30 px от центра (819.5, 615.5) |
| HFOV | IMX219-160 на 1640×1232: около 120–130° |
| три разрешения | fx, cx, cy меньших разрешений близки к пересчёту полного (`K_scaled_from`: разница — доли пикселя) |

Демо (синтетические кадры, известный объектив f = 734.5, D = 0, через JPEG):
35 кадров автозахватом за ~35 с; 1640×1232 — f 734.6, cx 819.9, cy 615.9,
средняя ошибка 0.13 px; 820×616 — 0.13 px; 640×480 — 0.20 px. С дисторсией
D ≈ (0.045, −0.012, 0.004, −0.001) тест восстанавливает fx в пределах 0.5 px.

## Файлы

```
artifacts/calibration/<сессия>/intrinsics/camera_3/
  captures/000.png …            кадры 1640×1232 (серые, без потерь)
  rejected/                     убранные кнопкой
  imx219_1640x1232.yaml         формат ROS / sverk camera_calibration (camera_matrix, distortion_coefficients,
  imx219_820x616.yaml             distortion_model equidistant, projection_matrix, число кадров, отсев)
  imx219_640x480.yaml
  camera_3_1640x1232.json       K, D, ошибки, угол обзора — их читают станция и solve_extrinsics.py
  camera_3_820x616.json
  camera_3_640x480.json
  intrinsics_summary.json
```

Внешняя калибровка берёт `camera_N_1640x1232.json` из той же сессии автоматически
(или из `--intrinsics <каталог>`).

Пересчитать по сохранённым кадрам (например, с другим размером клетки):

```bash
scripts/hardware/calibrate_intrinsics.sh offline artifacts/calibration/<сессия>/intrinsics/camera_3/captures camera_3 --board-square-mm 21.8
```

## Чего нет

- На реальных камерах станция не запускалась: проверено на демо и тестами
  (`tests/test_charuco_calibration.py`).
- Модель только fisheye: для IMX219-160 pinhole (`plumb_bob`) не подходит.
