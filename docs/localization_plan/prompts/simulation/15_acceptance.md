# S15 — Приёмка всей системы в симуляторе

> Фаза SIMULATION. Все работы и критерии этого этапа выполняются на Gazebo,
> синтетических данных и replay. Драйверы IMX296/libcamera, udev, реальные камеры,
> сеть узлов захвата и аппаратный trigger — только фаза HARDWARE после S15.
> Общие интерфейсы и поля конфигурации допустимы; отсутствие оборудования
> не блокирует этап и не требует спрашивать пользователя о подключении камер.


Выполни prompts/00_context.md. Выполни SIM-приёмочный набор из 04_implementation_plan.md
на независимых seeds и hold-out сценах: два ровера, все стили/свет, калибровка
из изображений, швы, окклюзии, потери/задержки/отключения, replay/reset,
30-минутный прогон с панелью, шестью previews и записью.

Подготовь sim_acceptance_report.md: для каждого SIM-критерия PASS/FAIL,
команды, версии, ссылки на записи, точность и частоты по wall time/sim time,
accepted measurement Hz, prediction horizon, latency/age, ID switches.
Ground truth используй только в evaluator; калибровку нельзя брать из эталона.
Сохрани launch sim/replay, веса, конфигурации, калибровки, dataset manifest,
operator_runbook_sim.md и отчёт о визуальной проверке панели и Gazebo.

Если SIM-критерий не пройден, вернись к соответствующему S-этапу и зафиксируй
регрессионный тест. Отсутствие реальных камер не является причиной FAIL.
Непроверенные hardware-критерии перенеси в hardware_backlog.md, не смешивая
их с SIM-приёмкой. Успех в симуляции не подтверждает качество на реальном стенде.

Gate SIM_ACCEPTED выставляй в STATUS.md только по результатам всех обязательных
SIM-проверок. После этого остановись: H01 запускается отдельным запросом
пользователя, автоматический переход к железу не нужен.

## Дополнение из согласованного ресерча

Прочитай `docs/localization_plan/05_research_integration.md`.
Дополнительный обязательный артефакт: research_comparison_report.md по R01–R06
и разделу интеграции 04_implementation_plan.md. SIM_ACCEPTED требует baseline
PASS и выполненные сравнения; альтернативы могут получить NOT_ACCEPTED с
измеренными причинами. Не обещай 100% coverage по сумме площадей. Отдельно
зафиксируй, какой layout/marker/camera/rover профиль прошёл, а какой требует
опоры, другой оптики или дополнительной камеры. Не понижай требования baseline
ради согласования с численными оценками исследовательского источника.
