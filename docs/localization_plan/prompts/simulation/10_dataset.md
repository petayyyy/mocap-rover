# Промпт 10 — Данные и обучение второго ровера

> Фаза SIMULATION. Все работы и критерии этого этапа выполняются на Gazebo,
> синтетических данных и replay. Драйверы IMX296/libcamera, udev, реальные камеры,
> сеть узлов захвата и аппаратный trigger — только фаза HARDWARE после S15.
> Общие интерфейсы и поля конфигурации допустимы; отсутствие оборудования
> не блокирует этап и не требует спрашивать пользователя о подключении камер.


Сначала выполни инструкции из `docs/localization_plan/prompts/00_context.md`.
Прочитай результаты предыдущего S-этапа в STATUS.md и используй существующие интерфейсы.

Создай воспроизводимую процедуру записи/разметки и manifest для детектора.
Используй пять стилей, свет, угол камеры, монтаж, масштабы, края, окклюзии,
свой ровер и трудные негативы. Для sim ground truth допустим только для label
creation/evaluation; проверяй видимость и реальные границы маски/box.

Раздели train/val/test по сценам, seed, траекториям и сессиям, а не соседним
кадрам одной записи. Сейчас обучай и проверяй на симуляционных записях; real dataset и real hold-out
отнеси к H04, их отсутствие не препятствует завершению этапа. Не обещай перенос из стилизованного sim без domain gap проверки.
Начальный класс rover плюс identity association; сравни bbox с segmentation/
keypoints, если точности проекции недостаточно. Изучи лицензию выбранного YOLO.

Обучи baseline только на доступных данных, сохрани weights/hash/config,
PR/recall по размеру и стилю, confusion friendly/opponent и downstream XY error.
Экспорт ускоренного runtime должен иметь equivalence check. Если данных/ресурсов
недостаточно, подготовь полный pipeline и явно оставь обучение незавершённым.

В конце обнови STATUS.md и дай команды воспроизведения результата.
