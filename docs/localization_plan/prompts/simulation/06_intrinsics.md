# Промпт 06 — Объективы и внутренняя калибровка

> Фаза SIMULATION. Все работы и критерии этого этапа выполняются на Gazebo,
> синтетических данных и replay. Драйверы IMX296/libcamera, udev, реальные камеры,
> сеть узлов захвата и аппаратный trigger — только фаза HARDWARE после S15.
> Общие интерфейсы и поля конфигурации допустимы; отсутствие оборудования
> не блокирует этап и не требует спрашивать пользователя о подключении камер.


Сначала выполни инструкции из `docs/localization_plan/prompts/00_context.md`.
Прочитай результаты предыдущего S-этапа в STATUS.md и используй существующие интерфейсы.

Реализуй импорт/экспорт ROS CameraInfo/OpenCV YAML и внутренний формат.
Поддержи pinhole/rational и fisheye с явным выбором модели, K/D/raw/rectified,
размер кадра, ROI/binning/flip. Общее focal_length_mm с per-camera overrides —
метаданные и прогноз покрытия, не замена измеренной матрицы.

Мастер калибровки: ChArUco/доска с известными размерами, сбор разных ракурсов
и покрытия поля, фильтрация плохих кадров, held-out оценка, residual heatmap.
Изменения объектива/фокуса/режима делают профиль stale до проверки.
Внешнее API выдаёт progress/result, не блокирует текущую одометрию.

Тесты: distortion/undistortion round-trip, crop/scale, несовместимые режимы,
повреждённый файл, повторная коррекция, недостаточное покрытие кадрами.
Критерий: сохранён полный calibration report; измеренная K не меняется от
редактирования только focal_length_mm; неподтверждённые intrinsics видны оператору.

В конце обнови STATUS.md и дай команды воспроизведения результата.

Для проверки дисторсии добавь контролируемую синтетическую модель и тестовые
кадры: нулевой D текущей pinhole-камеры не проверяет исправление дисторсии.
Проверяй по отложенным изображениям и известным только evaluator параметрам;
измеренные solver параметры не подменять истиной из генератора.
